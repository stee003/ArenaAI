# JobProof SEO and Free-Tool Content Plan

The product should acquire users through small, specific, high-intent pages. Do not write generic marketing blogs first. Build pages that local service owners search when they need immediate help.

## Free tools to publish as SEO pages

Each tool already exists inside the MVP UI and can later become its own route.

1. `/tools/google-review-qr-code-generator`
   - Target: `google review qr code generator for small business`
   - CTA: Create 2 free JobProof pages

2. `/tools/google-review-request-template`
   - Target: `google review request text message template`
   - CTA: Generate review request from completed job

3. `/tools/google-business-profile-post-generator`
   - Target: `google business profile post examples for contractors`
   - CTA: Turn every job into a GBP post

4. `/tools/contractor-before-after-caption-generator`
   - Target: `before and after captions for pressure washing`, `before and after captions for cleaning business`
   - CTA: Create a proof page

5. `/tools/review-reply-generator`
   - Target: `google review reply examples for small business`
   - CTA: Save replies in JobProof

6. `/tools/local-service-roi-calculator`
   - Target: `marketing roi calculator for contractors`
   - CTA: Start $19/month plan

## Niche landing pages

Create one page per niche using the same structure:

- `/pressure-washing-marketing-tool`
- `/cleaning-business-review-tool`
- `/landscaping-google-review-tool`
- `/painting-contractor-portfolio-tool`
- `/handyman-marketing-tool`
- `/junk-removal-review-tool`
- `/mobile-detailing-marketing-tool`

### Page structure

1. Hero: `Turn completed [niche] jobs into reviews and local SEO content`
2. Problem: jobs disappear after invoice
3. Demo: before/after proof page
4. Assets generated: review request, QR, GBP post, social caption, portfolio page
5. Pricing: free, $19, $39
6. CTA: create free proof

## Internal link map

Every article should link to:

- The relevant niche landing page
- Google review QR tool
- GBP post generator
- Main app/builder

Every tool page should link back to:

- Pricing
- Niche pages
- One educational article

## SEO validation target

Within 30 days, publish at least:

- 3 tool pages
- 3 niche pages
- 6 articles

Do not wait for perfect design. The goal is to learn which queries bring signups.
