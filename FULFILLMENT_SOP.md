# JobProof Fulfillment SOP

Use this when a customer pays for the $49 beta setup.

## Promise

Deliver 5 job proof pages within 24-48 hours.

Each job gets:

- Public proof page
- QR code
- Google review request SMS/email
- Google Business Profile post
- Facebook/Instagram caption
- Testimonial prompt
- Alt-text suggestions

## Step 1: collect intake

Send the intake email from the in-app Fulfillment Kit.

Ask for:

1. 2-5 photos per job
2. Service type for each job
3. City/neighborhood
4. One sentence about what was done
5. Google review link
6. Phone and website for quote requests

## Step 2: create business profile

In JobProof:

- Set business name
- Set service area
- Set primary service
- Set phone
- Set website
- Set Google review link
- Set offer/CTA

## Step 3: create five job pages

For each job:

1. Upload photos
2. Enter service type
3. Enter city/neighborhood
4. Add notes
5. Generate JobProof package
6. Open public proof page
7. Check grammar and claims
8. Copy link
9. Download QR code if needed
10. Print sales sheet if useful

## Step 4: quality control

Before delivery, check:

- No invented facts
- No "5-star review" language
- No review incentives
- No review gating
- Correct phone number
- Correct review link
- Correct city/service
- Public page opens
- Portfolio page opens

## Step 5: deliver

Use the delivery email from the in-app Fulfillment Kit.

Include:

- 5 proof page links
- Portfolio link
- Instructions for use
- Reminder about honest reviews only
- $19/month subscription link

## Step 6: follow-up

After 3 days:

- Ask if they used the pages
- Ask if any customer clicked/called
- Ask what was confusing
- Ask for testimonial if they liked it

After 7 days:

- Ask for more completed jobs
- Offer ongoing $19/month plan

## Success definition

A customer is successful if they:

- Sends at least one proof page to a prospect
- Uses at least one review request message
- Posts at least one GBP/social post
- Understands how to send future jobs
- Agrees the workflow saves time

## If they churn

Ask one question:

> What would have needed to happen for JobProof to be worth keeping?

Record the answer in the prospect CRM notes.
